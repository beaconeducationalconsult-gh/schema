# Schema — Repository Overview & UX Redesign Proposal

> **Teaching Companion** — offline-first PWA that answers “What am I teaching, right now?”  
> **Repo:** `beaconeducationalconsult-gh/schema` · **Branch:** `arena/01a0f5b2-schema` · **Date:** 2026-10-01  
> **Audience:** teachers using the Ghana NaCCA curriculum (Basic 1–9), low-connectivity classrooms, projector teaching.

---

## Part 1 — Repository Overview

### 1.1 What it is

An **offline-first, installable PWA** with **no backend**. All data lives in IndexedDB (Dexie) and can be exported as JSON. It ties three things together:

1. **Timetable** → when you teach
2. **Curriculum** → what the syllabus says (NaCCA strands → sub-strands → standards → indicators)
3. **Lesson activities** → how you teach it (exercise, correction, image, video, reading, discussion, assignment) + notes/history

The home screen (`/`) is live: it matches the current time to the timetable, shows a countdown ring, the current standard, and lets you add teaching moves without leaving the page.

### 1.2 Tech Stack

| Layer | Choice | Why it matters |
|---|---|---|
| **UI** | React 19 + React Compiler, React Router 7, Tailwind CSS 4 | File-per-card architecture, route-split chunks |
| **Data** | Dexie 4 + `dexie-react-hooks` `useLiveQuery` | Live queries → any tab/screen/backup instantly reflects |
| **PWA** | `vite-plugin-pwa` + Workbox, `sw-notifications.js` | Installable, offline, system notifications via `importScripts` |
| **Build** | Vite 8, pnpm, Oxlint, Vitest + Testing Library + fake-indexeddb | Fast dev, strict lint, IndexedDB tests without a browser |
| **Theming** | `src/theme.css` generated by `scripts/gen-theme-css.mjs`, `localStorage` keys `tc-theme`/`tc-projector` | Dark mode re-maps variables, not `dark:` overrides; projector mode = larger type |

**Scripts:** `pnpm dev` (5173), `pnpm build`, `pnpm preview` (4173), `pnpm test`, `pnpm lint`, `pnpm theme:gen`.

### 1.4 Data Model (Dexie `TeachingCompanion`, v2)

```
subjects ──< strands ──< subStrands ──< standards ──< lessons
  │                                              ├─< activities (type, order, duration, done)
  │                                              ├─< notes (tags, createdAt)
  │                                              └─< resources (image/video, url, caption)
  │
timetable (dayOfWeek, startTime, endTime, subjectId, classLevel, room)
               └─< lessons [timetableId+date]

settings (key/value): profile, terms, prefs {weekStartsOn, includeWeekend,
  defaultActivityMinutes, reminderMinutes}, currentStandardBySubject,
  lastBackupAt, onboarded, seededAt
```

Backups are **merge-idempotent** via `MERGE_ORDER` identities (e.g. subject by `name`, strand by `subjectId+name`).

### 1.5 Routing & Navigation (`src/App.jsx`)

| Path | Screen | Loader |
|---|---|---|
| `/` | `NowScreen` (eager) | `useNow` + `loadNowContext` |
| `/schedule` | `WeekScreen` (lazy) | `loadWeek(weekStart)` |
| `/curriculum` | `CurriculumScreen` (lazy) | `loadSubjectTree` |
| `/lesson/:id` + `?guided=1` | `LessonScreen` / `GuidedMode` | `lessonsFull.hydrate` |
| `/notes` | `NotesScreen` | `noteRepo.allWithContext` |
| `/history` | `HistoryScreen` | history queries + `Filters` |
| `/settings` | `SettingsScreen` | `getSettings` (live) |
| onboarding | `OnboardingScreen` | `isOnboarded` gate in `App.jsx` |

`AppNav` mounts under the routes (hidden in `?guided=1`). Four primary tabs + `More` sheet (History, Settings, Projector toggle). `ClassReminders` + `PwaBanners` + `DialogHost` are global.

### 1.6 Key Live-Data Patterns

- **Writes never inside `useLiveQuery`** — e.g. `ensureNowLesson` runs in a `useEffect` keyed by `slotId:dateKey`.
- **Prefs** are reactive via `usePrefs()` and `savePrefs(patch)`; Week screen and reminders read the same source.
- **Reminders** poll every 10s, deduped in `localStorage` key `tc-reminded`, toast when focused, system notification when unfocused.

### 1.7 Demo Data (`src/db/seed.js`)

Opt-in only (onboarding or Settings → Reset). 4 subjects (Math, English, Science, Computing), ~8 standards with SVG diagrams, Mon–Fri timetable, sample lessons/activities/notes. Never auto-seeds if subjects already exist.

## Part 2 — Why It Feels Cumbersome (UX Audit)

We audited against Nielsen + mobile thumb-zone heuristics and counted taps for core tasks.

### 2.1 Friction Map (current)

| Area | What the teacher sees | Why it hurts | Heuristic violated |
|---|---|---|---|
| **Bottom nav** | `Now` · `Week` · `Curriculum` · `Notes` · `More` (History, Settings, Projector) | `Week` label ≠ “Timetable” mental model; 2 everyday destinations hidden behind 1 extra tap + sheet; Projector toggle is buried but needed *while* teaching | Visibility, Efficiency |
| **Now screen (home)** | StatusBanner (gradient + ring + slot picker) + ClassCard + CurriculumCard + ActivityPromptBar (7 colored buttons) + ActivityFeed + NotesStrip + LessonActions (3 CTAs) | 6 stacked cards + backup banner = 2–3 viewports of scroll before “Done”. `Complete & Advance` appears **3×** (Feed header, LessonActions, ClassCard overflow). 7 activity buttons wrap awkwardly (`grid-cols-4` → 4+3 on mobile) and each opens a 2-step modal. Slot override is a tiny native `<select>` in the banner. Cognitive overload. | Minimalism, Consistency, Error prevention |
| **Schedule / Week** | Grid / List toggle + `✎ Edit Slots` toggle + `Include weekend` checkbox + `◀ week ▶` + `Today` + `Print` + `+ Add Slot` | 3 toggles in header. **Mode confusion:** tap = open lesson *or* edit slot depending on `editMode`. No drag/drop, no duplicate/copy. Print button prominent but rarely used. | Visibility of system status, User control |
| **Curriculum** | Horizontal subject pills (overflow hidden) + single-open accordion (Strand ▸ Sub-strand ▸ Standards) + `+ Standard` inline + `Delete` text links + `⬆ Bulk CSV` | Only 1 strand + 1 sub-strand open at a time → can’t scan. 3–4 taps before you even *see* a standard. No search/filter/progress. Bulk import format invisible until modal. Delete links are 11px, easy to miss/tap. | Recognition > recall, Flexibility |
| **Lesson** | Toolbar + Header + StandardCard (big dropdown of *all* standards, truncated 40 chars) + TeachingPlan (Routine + Add) + NotesPanel + 5 modals | Standard switcher lists 50–100 items unsorted, no search. Empty state pushes *two* large CTAs. Activity reordering via tiny ▲▼ + drag. Modals stack (`ActivityPicker` → form, `RoutineTemplateModal` with preview, `CompleteLessonModal`, `ResourceManager`, `StandardQuickEdit`). | Minimalism, Help & docs |
| **History / Notes** | Separate screens, both with filters + lists | History = date range pills + subject/status/sort/search; Notes = separate tag + subject + search + composer. Same data, two taxonomies. No unified “what I taught” search. | Consistency |
| **Onboarding** | 3-step wizard: About you → Term dates (3 terms, 6 date pickers) → Subjects (pick + custom) → Demo toggle → Restore backup | Term dates are mandatory-feeling but tedious; Ghana school year could be a preset. `Restore backup` as a secondary link in step 1 is undiscoverable. Skipping is allowed but outcome unclear. | Efficiency, Guidance |
| **Settings** | Profile + Terms + Display + Prefs + Backup + Storage + About, with draft + `Save` + floating “Unsaved changes” pill | Save model is inconsistent: Week’s `Include weekend` writes live via `savePrefs`, but Settings uses a **draft + Save** pattern. “Backup since X days” calculation is live but export is manual. | Consistency, Error prevention |
| **Visual** | 10–11px uppercase labels, `text-[10px]`, low-contrast `text-slate-400`, many border colors, emoji + lucide mix, `bg-slate-50` everywhere | Hard to read on sunlit projector, tiny tap targets (px-2 py-0.5), no clear hierarchy. Activity colors (7 hues) compete with curriculum slate. | Aesthetics, Accessibility |

### 2.2 Tap-Count Analysis (real tasks)

| Task | Current taps + scroll | Pain |
|---|---|---|
| **Add a 10-min Discussion to today** | Now → scroll to prompt bar → tap Discussion (1) → type → `Save` (1) → dismiss modal. 2 taps + typing, but must *find* the bar after 2 cards. | Discoverability |
| **Change current standard for Math** | Now → tap dropdown in CurriculumCard (1) → scroll 30+ options → select. Or Curriculum → pick Math pill → open strand (1) → open sub-strand (1) → tap “★ Current” (1). 1–4 taps. | Choice overload |
| **Create a new timetable slot Tue 10:00 Science** | Week → `+ Add Slot` (1) → pick day/time/subject/room → Save (1). But if `editMode` on, tap behavior flips without warning. | Mode error |
| **Add a new Standard under Science** | Curriculum → scroll pills → tap Science (1) → tap Strand (1) → tap Sub-strand (1) → `+ Standard` (1) → type → Save. **5 taps** to start typing. | Depth |
| **Start teaching with timer** | Now → `Open Lesson Plan` (1) → Lesson → `▶ Guided Mode` (1) → `Start Timer` (1). 3 taps across 2 screens. | Flow break |

**Core insight:** the app optimizes for *completeness* (every field exposed) rather than *teaching flow* (one primary action at a time). Teachers in a 40-min period need **one thumb, one decision, one tap**.

### 2.3 What’s Already Good (keep)

- **Countdown ring + banner** — instantly answers “how long left”.
- **Guided Mode** — projector-friendly, timer, keyboard ← → / Space, wake-lock, chime. Best part of the app.
- **Live Dexie queries** — edits propagate without reload; huge for multi-tab/projector.
- **Offline-first + bulk import + idempotent merge** — correct for Ghana field conditions.
- **Demo data opt-in** — respectful, not forced.

## Part 3 — Design Principles for the Redesign

1. **One screen = one job.** `Today` teaches. `Plan` schedules. `Library` finds. No card soup.
2. **Zero-mode.** No “edit mode” toggle. Long-press / swipe reveals edit; tap always does the primary thing.
3. **Progressive disclosure.** Show 3 things now, hide the rest behind “Show more” — not 7 buttons + 6 cards.
4. **Smart defaults > forms.** Pre-fill from standard exemplars / last activity; details are *optional* (expand).
5. **Thumb zone.** Primary CTA is a bottom sticky bar (reachable one-handed), not scattered links.
6. **Search, not scroll.** Curriculum/history/notes get a single search + filter bar (fuzzy).
7. **Make Guided Mode the hero.** It *is* the teaching experience; entry must be 1 tap from `Today`.
8. **Readable at 3 meters.** 14px minimum, 16px+ in projector, 44px tap targets, contrast-checked.

## Part 4 — Proposed Information Architecture (simplified)

### Before

```
Bottom: Now | Week | Curriculum | Notes | More(History, Settings, Projector)
Screens: 6 + onboarding + 2 lesson modes + 5+ modals
```

### After (recommended) — 3 primary + utility header

```
Header (all screens): [School · Class]  ·  [🔍 Search]  ·  [Avatar → Settings]
Bottom: Today | Plan | Library          +  FAB (+ Add) context-aware
        Today = Now + next class + today’s lessons (was Now)
        Plan  = Week (timetable) + lesson list in one place (was Week + History)
        Library = Curriculum + Resources + Notes unified with search (was Curriculum + Notes + History)
Guided Mode becomes a full-screen takeover from Today/Plan (1 tap)
```

**Why 3:** Matches teacher mental model — *What am I doing now?* / *What’s this week?* / *Where is the content?*  
History, Notes, Resources are *views* of Library, not top-level destinations. Settings moves to header avatar (where teachers expect it), freeing bottom nav.

**Migration path (non-breaking):** keep `/schedule`, `/curriculum`, `/notes`, `/history` routes as aliases; new nav just *labels* them differently. No data change, tests keep passing.

## Part 5 — Screen-by-Screen Before → After

### 5.1 Navigation

**Before:** 4+More, `More` sheet hides History/Settings, Projector toggle in sheet.  
**After:**

- Bottom bar: **Today** (Timer icon) · **Plan** (CalendarDays) · **Library** (BookOpen) — 3 large 44px targets, label 12px, active shows pill.
- Header: left = class badge (`Basic 6 · Rm 4`), center = search (opens command palette `⌘K`), right = teacher avatar → Settings/Backup/Display.
- **FAB** bottom-right (above nav) = `+` that adapts: on Today = add activity, on Plan = add slot, on Library = add standard/note.
- Projector toggle floats in Guided Mode + header, not in bottom sheet.

**Impact:** 1 less tap for History/Notes, 0 taps to discover Search, thumb-reachable primary.

### 5.2 Today (Today replaces Now) — the biggest win

**Before layout (stack):**
```
[StatusBanner gradient + ring + slot select]
[backup banner]
[ClassCard: color bar + Open Lesson Plan + Complete buttons]
[CurriculumCard: strand/sub-strand + indicator + exemplars + gallery + switcher]
[ActivityPromptBar: 7 color buttons → 2-step modal]
[ActivityFeed: checklist + Complete & Advance + Edit Plan link]
[NotesStrip: tag pills + input + list]
[LessonActions: Open / Guided / Complete grid]
```

**After layout (single flow, 1 viewport primary):**

```
Header: Today, Mon 30 Sep · IN CLASS · 23 min left   [ring 48px]   [Live ▼]
Hero Card (one):
  Science · Basic 6 · Lab 1 · 09:00–10:00
  [● Live 23 min]  Strand 1 · Diversity of Matter
  B6.1.1.1 Classify plants by root systems  [Change ▼]
  [▶ Teach Now]  [View plan]          ← sticky bottom bar on scroll

Teaching checklist (collapsible):
  ☑ 1. Starter — observe roots (8 min)  [done]
  ☐ 2. Reading — textbook p.42 (10 min)  [▶ timer]  · drag handle
  ☐ 3. Group discussion (12 min)
  [+ Add step  ·  ⚡ Use routine]  ← one row, not 7 buttons

Notes: [Add note…]  (inline, not a card)  [All notes →]
No backup banner inline — shows as dismissible toast once.
```

**Changes & why:**

- **Merge 6 cards into 1 hero + 1 checklist.** Teacher sees *class + standard + what to do next* without scrolling.
- **7 buttons → `+ Add step`** that opens a **single** sheet: type pills at top, title/content/duration below, Save. Picks exemplar as placeholder, not pre-filled draft. + `⚡ Use routine` as secondary.
- **One `Teach Now` CTA** (was 3 duplicates) → opens Guided Mode directly. `View plan` is secondary text link.
- **Slot switcher** moves from banner `<select>` to `Live ▼` pill (shows `Live` vs `Preview: Tue 08:40 Math`) — larger, clearer.
- **Backup reminder** is a toast, not a persistent banner that pushes content down.
- **All typography ≥14px**, hero title 20px/24px, projector bumps to 24px/32px.

**Task improvement:** Add Discussion to today = `+ Add step` (1) → tap Discussion pill (1) → `Save` (1). Same taps, but *no hunting* and no second modal.

### 5.3 Plan (Week + History unified)

**Before:** WeekScreen has Grid/List + Edit mode + Include weekend + week nav + Add Slot + Print in header; History is separate screen with duplicate filters.  
**After:**

- **Single Plan screen with 2 tabs:** `Timetable` | `Lessons`
- `Timetable` tab: default **List on mobile** (1 column, swipe left to edit/delete), Grid on ≥768px auto. No `Edit mode` — long-press a slot → `Edit · Duplicate · Delete` sheet. `+ Add slot` is FAB. Week nav stays, `Include weekend` moves to header `⋯` menu, `Print` becomes share icon in same menu.
- `Lessons` tab: the old History (filters + stats + CSV) but filtered to *this week* by default, with `All` toggle. Each row shows `Mon 07:40 Math — Fractions` + status dot; tap → lesson.
- **Lesson creation is implicit:** tapping a future slot creates the lesson (existing `ensureLessonFor`), so `Plan → Timetable → tap Tue 10:00 Science` = lesson ready.

### 5.4 Library (Curriculum + Notes + Resources) — search-first

**Before:** Pill row → accordion (1 strand + 1 sub-strand open) → StandardRow with tiny `Delete` links → InlineAdd → Bulk CSV modal. No search, no progress.  
**After:**

- **Sticky search bar:** `Search standards, indicators, exemplars…` (fuzzy, debounced) + subject filter pills that wrap (not scroll) + `+ Add standard` + `Import` buttons.
- **Flat list (default) + Tree toggle:** Search results show as flat cards: `[Math · Strand 1 > B6.1.3]  B6.1.3.1.1 Compare fractions …` + progress dot (● not taught, ◐ in progress, ● done). Tree view is optional (same accordion but allows *multiple* open, and shows counts inline).
- **Card actions:** `⋯` menu (Edit, Media, Set as current, Delete) — no tiny text links. `Set as current` shows a clear `★ Current` badge, not just border color.
- **Add flow:** `+ Add standard` → sheet with `Strand` / `Sub-strand` dropdowns (create new inline with `+`) + `Content standard` / `Indicator` / `Exemplars` — one place, not per sub-strand.
- **Bulk import** button opens the same sheet with `Paste CSV / TSV` + `Download template` link + live preview table.
- **Notes & Resources** are tabs inside Library (`Standards` | `Notes` | `Media`) but share the same search. Notes composer stays, but filter pills move to library header.

**Result:** Find “fractions” in 1 search vs 5 taps through tree; scan 20 standards without opening/closing.

### 5.5 Lesson & Guided Mode

**Before:** 5 stacked sections + 5 modals + small `▶ Guided Mode` link. ActivityPicker is 2-step.  
**After:**

- **Lesson = single scroll with sections:** Header (date/status/room editable inline) → `Standard` (same card but switcher is search, not 100-item dropdown) → `Teaching steps` (ActivityList with larger drag handle, swipe to delete, tap to edit inline) → `Notes` → `Media`.
- **`+ Add step` sheet** identical to Today (consistency).
- **Guided Mode is primary:** `▶ Teach` button is large, full-width, sticky bottom on Lesson. Inside Guided Mode, keep existing excellent timer/keyboard/wake-lock, but add: step dots at bottom, swipe left/right, larger `Done & Next` (48px), and a persistent `Exit` + `Projector` in top bar.
- **Activity editing inline:** tap activity title → becomes input; duration is a stepper (±1) not number field.

### 5.6 Onboarding — 1 page, not 3

**Before:** 3 steps + 6 date pickers + custom subject flow + demo toggle confusion.  
**After:**

- **Single page:** `Your name` · `School` · `Class` (autocomplete: Basic 1–9, JHS 1–3) · `Subjects` (pill picker + `+ Custom`) · `School year` (preset: `2025/26 Ghana` auto-fills Term 1/2/3 dates; `Customize dates` expands if needed) · Primary CTA: `Start teaching` + secondary `Try demo data` + `Restore backup` as link. All fields optional with `Skip` that still creates 2 sample subjects so Today isn’t empty.

### 5.7 Settings & Backup

**Before:** Draft + Save + floating pill vs live prefs inconsistency.  
**After:** **Auto-save** everywhere (like prefs already do) — no Save button, no pill. Sections: `Profile` · `School year` · `Display (Theme/Projector)` · `Preferences` · `Backup` (Export → toast “Backup saved”, Import → `Merge (keep both)` / `Replace` radio + preview counts) · `Danger zone` (Reset demo). Export offers `Share` (Web Share API) + `Download JSON`.

### 5.8 Visual System Cleanup

- **Type scale:** 12px labels → **12px minimum, 14px body, 16px card titles**, projector +2 steps. Remove `text-[10px]`.
- **Tap targets:** 44px minimum, `px-3 py-2` → `px-4 py-3` on primary actions.
- **Color:** Keep subject colors for timetable dots only; activity colors become **left border + icon** not full button fill (reduces rainbow noise). Use `bg-surface` + `border` consistently.
- **Icons:** All `lucide-react`, no emoji for actions (keep emoji in Guided Mode hero for warmth if desired).
- **Motion:** 150ms `transition` on sheet/modal, no bounce.
- **Empty states:** Illustrate next step with `+ Add` in empty state itself, not just text.

## Part 6 — Interaction Patterns to Add (low code, high impact)

| Pattern | Where | Effort | Impact |
|---|---|---|---|
| **Command palette (`⌘K` / `Ctrl+K` + 🔍 header)** | Global search: `Go to Math standard…`, `Add activity`, `Today’s lessons` | Low | Very high — power users skip all nav |
| **`+ Add` FAB (contextual)** | Today/Plan/Library | Low | High — one thumb action everywhere |
| **Sheet, not modal** | Activity add/edit, slot edit, standard add | Low | High — feels like mobile OS, less jarring |
| **Swipe actions** | Activity rows, timetable slots, notes | Low | High — edit/delete without mode |
| **Inline edit** | Lesson header, activity title/duration | Medium | High — stay in flow |
| **Fuzzy search** | Library, History | Low (use `fuse.js` or simple includes) | Very high |
| **Undo toast** | Delete standard/slot/activity | Low | High — forgiveness |
| **Share + Print** | Lesson, Week | Low | Medium |
